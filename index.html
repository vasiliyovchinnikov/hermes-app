Hermes

Личный ИИ-агент (автоматизация задач, почты и календаря). Страницы бренда для Google OAuth.

Политика конфиденциальности (Privacy Policy)

Hermes — персональный ИИ-агент владельца этого аккаунта. Доступ к Google-данным (Gmail, Календарь, Диск, Таблицы, Документы) используется только по прямому поручению владельца аккаунта.

Какие данные используются

  • Письма и их содержимое — для поиска, сортировки, разбора деловой переписки и отправки сообщений по поручению владельца.
  • События календаря — для чтения, планирования и подтверждений.
  • Файлы и документы — для поиска, чтения и создания по поручению владельца.

Какие данные передаются

Данные не передаются третьим лицам и не используются для рекламы. Данные обрабатываются эксклюзивно лицом, которое администрирует Hermes (контакт ниже), и не хранятся дольше, чем необходимо для выполнения поручений владельца.

Управление доступом

Доступ полностью управляется владельцем аккаунта: включается, ограничивается и отзывается в любой момент через страницу безопасности аккаунта Google (Settings → Security → Third-party access).
